# Code of conduct

Nav Stack Lab is a teaching tool, and its issue tracker, pull requests and discussions should feel like a good
lab: people with different backgrounds, from first-year students to control engineers, asking and answering questions
about hard material without fear of looking foolish.

## What we expect

- Be welcoming and patient. Explain, do not condescend. A question that looks basic is usually a sign the lesson
  could be clearer, which is worth knowing.
- Argue about the mathematics and the code, not the person. "This derivation drops a term" is a review; "you do not
  understand control" is not.
- Give credit, cite sources, and say when you are unsure.
- Respect people's time: a reproducible issue with a run export, a focused pull request with the tests run.

## What we do not accept

Harassment, discrimination, personal attacks, sexualised language or imagery, publishing others' private
information, and sustained disruption of discussions. This applies in every project space (issues, pull requests,
reviews, discussions) and when representing the project elsewhere.

## Enforcement

Report a problem to the maintainer by email at the address on the GitHub profile of the repository owner, or by
opening a private security advisory on the repository if the report concerns the owner. Reports are handled
confidentially. The maintainer may edit or remove comments, commits and issues that break this code, and warn or ban
contributors, temporarily or permanently, in proportion to the behaviour.

This document is adapted from the ideas of the Contributor Covenant, version 2.1.
